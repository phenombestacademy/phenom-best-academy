# Cambridge International Curriculum — Examination Coverage Completion

## Verified pathway

Cambridge International describes a five-stage pathway: Early Years, Primary, Lower Secondary, Upper Secondary and Advanced. Its current qualifications and assessments include Cambridge Primary/Lower Secondary assessment, IGCSE, O Level, International AS & A Level, ICE, AICE and IPQ.

Phenom-authored resources are stored separately as canonical Library resources. Teachers can use canonical resources; editing remains a Super Admin function.

## Historical qualification

Cambridge Pre-U is not treated as a current qualification. Cambridge states that it has been withdrawn, with the last examinations in June 2023 and a resit in June 2024. It should be retained only as a clearly labelled legacy qualification if historical coverage is required.

## Nigeria progression

Cambridge states that Nigerian universities recognise Cambridge qualifications. Its guidance describes IGCSE/O Level requirements and Direct Entry routes using Cambridge International A Levels, while noting that individual university requirements can vary.
