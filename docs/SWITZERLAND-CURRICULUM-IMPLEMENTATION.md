# Switzerland Curriculum Implementation

## Finalisation checkpoint — 25 September 2026

Switzerland has been expanded without deleting or replacing any previously completed curriculum records.

### Live curriculum foundation
- `switzerland`: 322 curriculum topics
- `switzerland-education`: 780 curriculum topics
- Total Swiss topic anchors: **1,102**

### Resource packs and stored assets
For all 1,102 topic anchors, the following 14 core resource families are now present in the LMS resource-pack and asset layers:
- scheme of work
- lesson
- study note
- practice
- assessment
- answers
- marking guide
- revision
- teacher guide
- worked example
- activities
- workbook
- audio script
- video script

This gives:
- **15,428 published resource packs**
- **15,428 stored curriculum assets**
- **1,102 stored assets in each of the 14 core families**

The assets are database-backed, viewable/downloadable and non-editable by teachers. This is the LMS asset registry; it must not be represented as a claim that every item is a separately downloaded PDF/DOCX binary in object storage.

### Remaining specialist production
The detailed production queue remains intact for topic-specific and source-dependent work including:
- interactive activities
- simulations and virtual laboratories where appropriate
- differentiated and extension resources
- examination questions, answers and marking schemes
- pathway guidance
- source/topic reconciliation
- provenance and requirement mapping
- IQA/final completion audits
- additional source-specific resource expansion

Current retained detailed queue:
- **10,955 queued jobs**
- queued work is not counted as completed.

### Swiss curriculum architecture
The implementation preserves Switzerland's decentralised system:
- Lehrplan 21 — German-speaking and multilingual cantons
- Plan d'études romand (PER) — French-speaking Switzerland
- Piano di studio — Ticino
- cantonal upper-secondary curricula
- Gymnasial/Matura framework
- specialised upper-secondary pathways
- federal/SERI vocational education and training
- current vocational general-education reform/ABU 2030

EDK confirms that cantons are responsible for compulsory education and determine curricula, teaching materials and lesson allocations, while the three linguistic-region curricula provide the harmonised framework. The 2026 ABU 2030 implementation is retained in the vocational reconciliation layer.

### Integrity rule
No previously completed curriculum has been deleted. Existing Switzerland records, topics, source mappings, acquisitions and queues were retained. Queued specialist production is deliberately not marked completed until actual topic-specific assets and QA evidence exist.
