# Phenom Best Academy — application packaging plan

The V5 web application includes PWA metadata and is structured so the same web application can later be packaged for Android, iOS/iPadOS and Windows.

Planned release targets:
- Android APK/AAB — Google Play and direct download from the Academy site.
- Apple iOS/iPadOS — App Store/TestFlight; iCloud integration only where a specific Apple capability is appropriate.
- Windows — Microsoft Store and/or signed desktop installer.
- Amazon — Android-compatible distribution where appropriate.

Store accounts, signing certificates, package identifiers, privacy disclosures and final store submissions are external release steps and should be completed after the production web build is stable.
