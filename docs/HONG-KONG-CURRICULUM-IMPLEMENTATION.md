## Immediate-stock rule
Verified official EDB web resources are catalogued as external-link stock with provenance. A link in stock is not represented as a locally downloaded file.

## Queue rule
Each curriculum anchor has six queued production jobs:
1. topic reconciliation
2. full resource pack
3. resource expansion
4. assessment generation
5. teacher-guide generation
6. original examination-question generation

Queued does not mean completed. Assets are only marked generated/stored when an actual asset exists and passes the applicable checks.
