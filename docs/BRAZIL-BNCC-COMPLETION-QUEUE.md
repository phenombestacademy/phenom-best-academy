# Brazil BNCC — Completion and Queue Checkpoint

Status: implementation checkpoint recorded.

The Brazil BNCC layer retains authoritative MEC/CNE sources and currently stocked official resources. Remaining curriculum production must not be represented as complete until the underlying asset exists and passes provenance/IQA checks.

Production subtree:
- authoritative BNCC corpus extraction and reconciliation
- schemes of work by stage/year/component
- lesson plans and teaching materials
- student learning resources and study notes
- practice activities and worked examples
- formative/summative assessments
- revision resources
- teacher guides and student worksheets
- examination-question and answer/marking packs
- audio/video scripts and digital resources
- interactive activities/simulations where pedagogically appropriate
- differentiated/extension resources
- provenance and IQA validation

The queue currently contains 336 Brazil jobs. The official MEC ProBNCC library provides implementation guides, curriculum-development material, thematic notebooks, manager guides, and other support resources; the official BNCC site also provides navigable, PDF and spreadsheet forms of the Base.

Important integrity rule: BNCC is a normative reference, not itself a complete local curriculum. Brazilian state/municipal networks retain responsibility for contextualising and adapting curricula. Therefore generated schemes must be explicitly labelled as Phenom curriculum-support resources aligned to BNCC, not misrepresented as official MEC schemes.
