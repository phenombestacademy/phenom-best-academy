# Phenom Cambridge Library & Source Availability

## Purpose

The Cambridge release uses an add-don't-delete model. Existing curriculum records, resource specifications, source catalogues and generated assets remain available. New authoritative material is added and versioned rather than silently replacing useful historical material.

## Library classes

1. **Official-source catalogue** — authoritative Cambridge source links and metadata.
2. **Authorised stored resources** — material Phenom is permitted to store and serve.
3. **Phenom-authored resources** — original lessons, study notes, schemes of work, assessments, answers, teacher guides and other pedagogical resources aligned to verified Cambridge requirements.
4. **Restricted/link-only resources** — resources that must remain referenced rather than copied or redistributed.
5. **Generation-ready resources** — assets represented in the production queue and generated/stored by the appropriate worker when the source and rights conditions permit.

## Visibility

Everything is catalogued in the database and library layer first. Public release is a separate decision. The default for newly catalogued Cambridge material is private/internal until rights, source verification and QC permit wider publication.

## Completion gate

A Cambridge item is not marked complete merely because a database row, resource specification or generation job exists. Completion requires source/version verification, requirement mapping, pedagogical alignment, assessment alignment, resource availability, QC and appropriate storage/rights state.

## Current-source rule

Cambridge frameworks, schemes of work, teacher guides, progression grids, assessment support and qualification syllabuses are version-controlled. Secure School Support Hub material is not assumed to be publicly redistributable. Restricted material is catalogued and used only within permitted rights; Phenom may create original aligned resources where direct storage is not authorised.

## Add-don't-delete

Existing useful content is retained. A new source supersedes an old source only where it is demonstrably more relevant/current and no useful information is lost; otherwise both remain with clear version/source metadata.

## Release principle

Do not declare Cambridge complete until the final database audit confirms that the required curriculum hierarchy, authoritative requirements, resources, assessments, progression, pedagogy, QC and availability states are actually present.
