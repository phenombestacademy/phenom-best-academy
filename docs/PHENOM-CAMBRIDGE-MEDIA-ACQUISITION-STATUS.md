# Phenom Cambridge Media & External-Source Acquisition Status — 24 September 2026

## Purpose
This document records the Cambridge media/resource acquisition layer without claiming that a source has been physically stored when it has not.

## Verified source position
Collins International states that freely available accompanying audio can be accessed by direct OneDrive download without passwords. Collins also states that purchased-resource downloads are covered by a site licence and should not be shared elsewhere. Phenom therefore treats the free audio as an acquisition candidate, while retaining the internal/private licence boundary until storage and use rights are verified.

## Physical-storage status
- These records are not marked as physically stored merely because the source is downloadable.
- Current storage status remains link_only until a binary is successfully fetched, integrity-checked, rights-checked, uploaded to Phenom storage, mapped to the curriculum, and QC'd.
- No password-protected or purchase-only Collins material is bypassed.
- Cambridge School Support Hub/Teacher's Hub materials that require authenticated or school access remain catalogue/link-only unless Phenom has authorised access.

## Video
Cambridge/Cambridge GO documentation confirms that teacher resources can include audio, transcripts and video, but many teacher resources are access-controlled. Phenom will catalogue authorised video sources and store only resources that can be legitimately acquired.

## Google Drive / share.google
The supplied share.google links were catalogued previously. The current acquisition environment could not resolve those redirects into downloadable file bytes, so they remain source-gap/link-only records rather than being falsely marked as acquired.

## Completion rule
A media item becomes stored only after:
1. authorised access is confirmed;
2. binary is fetched;
3. content type/size is validated;
4. checksum is recorded;
5. storage upload succeeds;
6. curriculum/topic mapping is recorded;
7. licence/access metadata is retained;
8. QC passes;
9. Library availability is set to internal/private.

Public release remains a separate later decision.
