The 27 Statements of What Matters are represented as authoritative continuum anchors. Detailed progression material is to be generated against the official progression descriptions rather than treating the statement anchors as year-by-year syllabuses.

## Immediate official stock

Official Welsh Government / Hwb / Qualifications Wales resources have been registered as external-link stock. These records are not represented as locally downloaded files. Local storage will only be marked when the actual file has been retrieved and stored.

## Production queue

Each Statement of What Matters currently has six queued production jobs:

- topic reconciliation
- full resource pack
- resource expansion
- assessment generation
- original examination-question generation
- teacher-guide generation

All generated learner and teacher content must be original, curriculum-aligned, source-traceable and subject to IQA before publication.

## Important status rule

Queued is not generated. Generated is not stored. Stored is not published. This implementation does not claim completion of files that do not yet exist.
