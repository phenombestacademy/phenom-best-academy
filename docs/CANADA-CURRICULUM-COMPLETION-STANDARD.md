# Canada Curriculum — Phenom LMS Completion Standard

## Scope

Canada is represented as a pan-Canadian layer plus 13 separate provincial/territorial education systems:

- Alberta
- British Columbia
- Manitoba
- New Brunswick
- Newfoundland and Labrador
- Nova Scotia
- Ontario
- Prince Edward Island
- Quebec
- Saskatchewan
- Northwest Territories
- Nunavut
- Yukon

There is no single federal K–12 curriculum. Provincial and territorial authorities are responsible for curriculum, assessment, graduation and related education structures. CMEC provides pan-Canadian coordination and initiatives.

## Required hierarchy

Jurisdiction → stage/grade → subject/course → strand/domain → topic → subtopic/content description → learning outcome/objective → achievement expectation/standard → assessment → canonical source → resource → Library asset.

## Required coverage

Every jurisdiction must be populated from authoritative current sources, including where applicable:

- early learning and Kindergarten
- K–12/elementary-secondary curriculum
- all official subjects/courses
- curriculum strands/domains/topics/outcomes
- teacher guides and curriculum supports
- schemes/work programmes where officially supplied or legitimately derived
- lesson resources and notes
- worked examples and practice
- assessment frameworks
- provincial/territorial examinations and graduation assessments
- graduation credentials and requirements
- postsecondary admission/pathway information
- college, university, apprenticeship, technical and vocational pathways
- French/English and minority-language structures where applicable
- Indigenous education/curriculum frameworks where applicable
- accessibility, inclusive education and special education requirements where official

## Pan-Canadian assessment/pathways

Represent applicable CMEC and international assessment layers separately from provincial curricula, including PCAP and Canada's participation in PISA, plus credential-transfer and postsecondary information where authoritative.

## Resource requirements

A database metadata row is not completion. Each canonical source must be linked to an actual Library resource when the source is legally/technically available for storage. Human-readable resources must be viewable in the LMS and downloadable in appropriate formats (especially PDF where conversion is appropriate). Source formats such as HTML, DOCX, PPTX or other official formats should be retained when available and permitted.

## Integrity gate

Canada may only be marked COMPLETE after verification that:

1. all 13 jurisdictions are represented;
2. official source coverage is reconciled;
3. all applicable K–12 subjects/courses are mapped;
4. assessment/examination/graduation pathways are mapped;
5. topic/subtopic/resource relationships are complete;
6. canonical assets are physically accessible in Library where applicable;
7. generated human-readable derivatives exist where required;
8. no duplicate canonical assets exist;
9. no orphan topics, assets, jobs or Library records remain;
10. queued jobs have completed or have an explicit documented exception;
11. source provenance and version are retained;
12. final completion audit passes.

## Principle

Do not mark a jurisdiction complete merely because framework rows, topic seeds, or generation jobs exist. "Complete" means a human user can find, read, teach/study, assess against, and download the applicable material through Phenom LMS, with source provenance preserved.
