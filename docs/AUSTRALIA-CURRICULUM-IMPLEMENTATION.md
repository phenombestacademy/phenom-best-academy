# Australia Curriculum Implementation

## Status
Australia is represented as a national Australian Curriculum layer with Version 9.0 explicitly preserved, alongside the existing Australian Curriculum record. State and territory implementation differences must remain distinguishable.

## Verified live database baseline
- Australian Curriculum: 13 levels, 8 subjects, 35 framework components, 440 topics and 440 existing assets.
- Australian Curriculum Version 9.0: 3 levels, 24 subjects, 24 topics and 27 existing assets.
- Existing material is preserved; no existing curriculum or asset records are deleted or duplicated solely because Version 9.0 is present.

## Production queue
- Australia: 12,320 queued jobs.
- Australia AC v9: 672 queued jobs.
- Combined queued production jobs: 12,992.
- Queue status is explicitly retained as queued until authoritative ingestion, generation and IQA are actually completed.

## Required resource subtree
Every applicable curriculum topic is to be covered by:
1. Curriculum/programme
2. Level/year/band
3. Subject
4. Topic/subtopic
5. Learning objectives/outcomes
6. Scheme of work
7. Lesson
8. Study notes
9. Worked example
10. Practice set
11. Assessment
12. Revision guide
13. Teacher guide
14. Student worksheet/download
15. Audio script
16. Video script
17. Interactive activity
18. Simulation/virtual laboratory where pedagogically appropriate
19. Original examination questions
20. Answers/marking guidance
21. Differentiation/extension
22. Provenance and curriculum requirement mapping
23. IQA/final verification

## Authoritative baseline
ACARA Australian Curriculum Version 9.0 is the principal national F–10 reference. State and territory authorities determine implementation timelines and local delivery. Senior secondary Australian Curriculum subjects are a common national base, while state/territory authorities integrate content into their courses and certification systems.

## Completion rule
Existing records remain in stock. Missing material remains explicitly queued. No queued resource is represented as generated until it exists and passes IQA.
