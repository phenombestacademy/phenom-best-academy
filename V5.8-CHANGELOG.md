# Phenom Best Academy — V5.8 Final

## V5.8 focus
V5.8 keeps the V5.7 Tool Hub scope and refines the calculator experience for real phone use.

### Calculator / keyboard
- Floating calculator keyboard no longer occupies normal document space or pushes the Tool Hub screen.
- Keyboard can be minimised and recalled from a persistent floating button.
- Tapping the calculator expression/result calls the keyboard back.
- Basic and Scientific controls remain clearly separated from the Tool Hub service menu.
- Scientific keyboard adds hyperbolic functions, inverse hyperbolic functions, nPr/nCr entry, percentage handling, modulo, sign toggle and EXP scientific notation.
- Existing memory, history, angle modes, fullscreen and calculator functionality are preserved.

### Language
- Onboarding now includes an Academy language choice that is persisted on the device.
- Tool Hub now exposes its own language selector.
- It follows the Academy language selection first.
- When no language has been selected, it uses the device/browser language and falls back to English — Nigeria.
- Speech voice selection follows the active Tool Hub language where the device provides a matching voice.

### V5.6/V5.7 preservation
- Unit Converter + live currency
- Formula & Units
- Graph Plotter
- English Literacy
- Language Translation + device speech
- All-Purpose Scanner & Creator
- Productivity helpers
- Tool Hub settings
- Tools Premium vs CPD entitlement model
- Paste, history and fullscreen calculator

### Security / Supabase
- Corrected `supabase/030_tools_and_cpd_entitlements.sql` so it matches the successfully applied live database function. The migration no longer references a non-existent `subscription_feature_grants.enabled` column.
- No media/storage RLS weakening was introduced.
