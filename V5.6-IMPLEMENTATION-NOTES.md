# Phenom Best Academy V5.6

V5.6 consolidates the V5.5 working site with the latest Academy Tool Hub and media-upload work.

## Main changes
- Rebuilt `/tools` as a full-width Phenom Calculator / Academy Tool Hub.
- Calculator keeps separate Basic and Scientific modes.
- Added Unit Converter with broad mathematics, physics, chemistry, engineering and data units plus live currency.
- Added Formula & Units with level filters and direct value solving/explanations.
- Added Graph Plotter.
- Added English Literacy services: spelling, definition, pronunciation, synonyms/antonyms, phonics, grammar, common mistakes, British/American comparison and IPA-style transcription.
- Added multilingual translation using the Academy AI route and device speech.
- Added All-Purpose Scanner & Creator: up to 10 image snapshots, OCR/processing, text/image reading and QR/Data Matrix/Aztec/PDF417/common barcode creation and scanning.
- Added Tool Hub settings for theme, font scale and keep-screen-on.
- Added copy/paste/edit workflows.
- Preserved the distinction between Tools Premium and CPD.
- Added server-side entitlement configuration so eligible language plans can unlock only the speech Tool capability they require.
- Reworked Super Admin media upload to use Supabase TUS resumable uploads with real progress reporting.
- Admin upload now shows filename, file type, size, transferred bytes, percentage, finalization and success/error state.
- Preserved Super Admin-only permanent Academy media write access; no public media-write permission was added.
- Added `tus-js-client` and `@bwip-js/browser` dependencies.
