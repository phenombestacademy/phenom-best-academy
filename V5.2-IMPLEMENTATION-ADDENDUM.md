# V5.2 implementation addendum

Implemented in this package and applied to the connected Supabase project through migration 026:

- School tenant isolation: school administrators operate their own school; Super Admin can operate across schools.
- Explicit class-teacher assignment and subject-teacher assignment.
- Teacher access is limited to assigned class/subject records; class teachers can see final assessment performance for their own class without editing subjects they do not teach.
- Attendance entry/editing is limited to the designated class teacher; school administrators are read-only for attendance; Super Admin retains correction control.
- Student ordinary records are limited to student/class teacher/school admin/Super Admin. Sensitive guardian/health/contact records are separated and can be opened to class teachers only through school-controlled access.
- Result entries are insert-only for ordinary users and protected from update/delete. Derived totals/percentages are generated server-side. Publication is the visibility gate for students/parents.
- Result-release notifications are queued on publication and the deployed `send-result-release` function can send them after the Academy email provider secrets are configured.
- Community supports friend requests, text messages, group conversations, ephemeral image/document/video sharing and WebRTC voice/video calls. Academy media storage is not used for those shared call/media payloads.
- Group owners/Super Admin can control membership; group sharing can be restricted for selected students.
- Phenom Calculator includes full-screen mode, on-screen keyboard, scientific calculations, snapshots, OCR/analysis, barcode workflows, currency conversion and multilingual translation. Limited translation permits unlimited single-word translation and a configurable sentence limit; Premium removes the sentence limit, subject to provider/fair-use limits.
- Locale selection includes Nigerian, British, American, Australian and Canadian English variants, Nigerian Pidgin, French, Spanish, Mandarin/Chinese and additional languages. The framework is translation-ready; full translation of every hard-coded page sentence requires the corresponding locale content/catalogue to be populated rather than being falsely claimed as automatic for every string.
- Company FAQ content was expanded around the Calculator, privacy, school isolation, teacher access, result publication, community and premium grants.
- PWA/app-packaging documentation is included for later Android, Apple and Windows store releases.

## External activation still required

Private provider credentials must be entered by the owner/admin in the provider or Supabase secret configuration. They must never be placed in GitHub, the ZIP or chat messages. This includes AI keys, Paystack/Flutterwave/Stripe/Interswitch production keys and webhook signing secrets, Resend email credentials and Google OAuth client credentials.

The project currently has no Auth users, so a Super Admin email cannot be confirmed until the owner creates the account. The database prevents a second Super Admin after the designated account is established.

## V5.3 Global localisation and curriculum layer

- The language selector now starts an application-wide localisation pass over rendered React text, rather than only changing the HTML `lang` attribute.
- A dedicated `translate-ui` Edge Function translates visible hard-coded UI strings in controlled batches for all supported locales, using server-side AI credentials only. It preserves placeholders, numbers, URLs, proper nouns and punctuation and is rate-limited.
- English variants remain native/localised variants rather than being machine-translated.
- School onboarding now records country, optional state/region and up to three curriculum frameworks.
- Current authoritative framework catalogue: Nigeria NERDC Basic Education Curriculum, England National Curriculum, Cambridge International Curriculum, and United States Common Core / state-standards-aligned framework. Each catalogue entry retains its official source URL and notes on scope.
- A school cannot select more than three curriculum frameworks. Selected frameworks drive the subject catalogue shown in the school workspace.
- The US option is deliberately described as state-standards-aligned because the United States does not have one federally mandated national school curriculum.
- The designated Super Admin email is stored only in the private Supabase configuration table. It is intentionally absent from source control and public client content.
